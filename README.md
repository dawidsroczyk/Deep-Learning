# Deep Learning Projects 🚀

This repository contains a collection of deep learning projects developed for educational purposes and as a reference for exploring various deep learning techniques and architectures. Each project focuses on a specific domain or task, providing insights into model design, training, and evaluation.

## Projects Overview

### 1. Convolutional Neural Networks 🖼️
This project focuses on image classification using the CINIC-10 dataset. It includes experiments with ResNet, a custom VGG-like architecture, transfer learning with EfficientNet, few-shot learning, and ensemble learning. The project emphasizes hyperparameter tuning, data augmentation, and performance evaluation.

📂 **Folder**: [`convolutional_neural_networks`](./convolutional_neural_networks)

---

### 2. Transformers 🔊
This project explores transformer-based architectures for speech command classification. It includes custom implementations of models like the Audio Spectrogram Transformer (AST) and compares their performance with convolutional neural networks (CNNs). The dataset used is the Speech Commands Dataset, and the project emphasizes preprocessing, training, and evaluation.

📂 **Folder**: [`transformers`](./transformers)

---

### 3. Generative Models 🐱🐶
This project investigates generative models for image synthesis, focusing on datasets of cats and dogs. It evaluates Variational Autoencoders (VAEs), Deep Convolutional GANs (DCGANs), and Diffusion Models. The project highlights the strengths and weaknesses of each approach, with experiments on latent space exploration and image quality assessment.

📂 **Folder**: [`generative_models`](./generative_models)
